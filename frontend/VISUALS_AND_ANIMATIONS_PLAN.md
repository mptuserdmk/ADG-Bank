# План внедрения медиа-ассетов из Figma и нативных анимаций в ADG-Bank

Данный документ представляет собой пошаговое инженерно-дизайнерское руководство по обогащению интерфейса ADG-Bank (Revolut UI) оригинальной графикой из дизайн-кита `.fig` (3D-иллюстрации, текстуры банковских карт, логотипы мерчантов, аватары) и микро-анимациями уровня нативных мобильных приложений (Spring-физика, свайпы шторок, 3D-наклон карты, анимированный тикер баланса, салют конфетти).

---

## 1. Архитектурный стек визуального слоя

| Категория | Технология / Инструмент | Назначение |
|---|---|---|
| **Анимационный движок** | `framer-motion` (v12) | Пружинная физика (springs), жесты drag-to-dismiss, переходы layoutId, staggered-списки |
| **Физика частиц** | `canvas-confetti` (+ `@types/canvas-confetti`) | Взрывы конфетти при успешных транзакциях, реферальных бонусах и кэшбэке |
| **Форматы графики** | WebP (24-bit альфа-канал) + SVG | Минимальный размер бандла при максимальной четкости на Retina 2x/3x дисплеях |
| **Шейдеры и 3D** | CSS 3D Transforms (`perspective`, `rotateX/Y`) | Гироскопический наклон карты и динамический блик (hologram shimmer) |

## ЭТАП 1: Извлечение, каталогизация и оптимизация ассетов

### 1.1. Маппинг хешей из `.fig` в семантические файлы
В распакованном контейнере `scratch_fig/images/` содержатся файлы с SHA-хешами. Создается скрипт каталогизации `scripts/process-figma-assets.mjs`, который связывает хеши с семантическими именами и конвертирует их в оптимизированный WebP/SVG:

```
frontend/public/assets/
├── cards/
│   ├── card-metal-spacegray.webp    # Текстура металлической карты Space Grey (1026x645)
│   ├── card-gradient-cyber.webp     # Неоновый голографический градиент (Cyber Pink/Purple)
│   └── card-virtual-matrix.webp     # Матричный узор одноразовой карты
├── 3d/
│   ├── gift-box-3d.webp             # 3D подарочная коробка для реферального баннера
│   ├── coins-wealth-3d.webp         # 3D золотые монеты для раздела Invest / Crypto
│   ├── vault-shield-3d.webp         # 3D сейф/щит для виджетов безопасности и сбережений
│   └── rocket-boost-3d.webp         # 3D ракета для крипто-пампа и бонусов
├── merchants/
│   ├── spotify.svg                  # Логотип Spotify для подписок
│   ├── apple.svg                    # Логотип Apple Store / Services
│   ├── netflix.svg                  # Логотип Netflix
│   ├── starbucks.svg                # Логотип Starbucks Coffee
│   └── deliveroo.svg                # Логотип доставки еды
└── avatars/
    ├── user-sarah.webp              # Портреты для блока Recent Payees
    ├── user-alex.webp
    └── user-john.webp
```

### 1.2. Внедрение в компоненты
* **`MarketingBanner.tsx`**: замена фонового блока на сочную 3D-иллюстрацию `gift-box-3d.webp` с парящим эффектом (floating effect).
* **`CardsScreen.tsx`**: отображение реальных фототекстур металлической и неоновой карты вместо плоских CSS-заливок.
* **`TransactionsSection.tsx`**: отображение цветных фирменных логотипов брендов вместо монохромных иконок категорий.
* **`RecentPayees.tsx`**: реальные фото-аватары с градиентным кольцом активности.

## ЭТАП 2: Подключение Framer Motion и жестовые шторки

### 2.1. Установка зависимостей
```bash
cd frontend
npm install framer-motion canvas-confetti
npm install --save-dev @types/canvas-confetti
```

### 2.2. Модернизация `ModalSheet.tsx` (Настоящий жест Swipe-to-Dismiss)
Замена стандартного CSS `transition` на компонент с физикой пружины:
* **Жест**: `drag="y"`, `dragConstraints={{ top: 0 }}`, `dragElastic={{ top: 0, bottom: 0.5 }}`.
* **Порог закрытия**: если пользователь потянул шторку вниз более чем на `100px` или отпустил со скоростью `velocity.y > 500`, вызывается `onClose()`.
* **Пружинная физика**:
  ```ts
  transition={{
    type: "spring",
    damping: 28,
    stiffness: 320,
    mass: 0.8
  }}
  ```
* **Индикатор зацепа (Drag Handle Pill)**: сверху шторки размещается закругленная плашка `w-10 h-1.5 bg-white/20 rounded-full cursor-grab active:cursor-grabbing`, которая слегка удлиняется при захвате.

## ЭТАП 3: 3D-наклон карты и голографический блик (Card Shimmer)

### 3.1. Создание компонента `InteractiveCard.tsx`
* **3D-трансформация**: отслеживание движения курсора мыши (на десктопе) или тача (на мобильных устройствах):
  * Вычисление нормализованных координат `x` и `y` от `-0.5` до `0.5` относительно центра карты.
  * Наклон по осям: `rotateY = x * 20deg`, `rotateX = -y * 20deg`.
  * Возврат в исходное состояние с мягким пружинным затуханием при `onMouseLeave`.
* **Динамический блик (Hologram Glare)**:
  * Радиальный градиент поверх текстуры:
    ```css
    background: radial-gradient(circle at ${glareX}% ${glareY}%, rgba(255,255,255,0.4) 0%, transparent 60%);
    mix-blend-mode: overlay;
    ```
* **Анимация переворота (Card Flip)**:
  * По клику на кнопку «Реквизиты» карта плавно переворачивается вокруг оси Y на 180° (`transform: rotateY(180deg)`), открывая обратную сторону с магнитной полосой, панелью подписи и кодом CVV.

## ЭТАП 4: Анимированный тикер баланса (NumberTicker) и микро-отклики

### 4.1. Компонент `NumberTicker.tsx`
* Когда баланс изменяется (например, после `AddMoneyModal` или `ExchangeModal`), цифры плавно прокручиваются барабанчиком вверх/вниз:
  ```tsx
  <NumberTicker value={balance} currency="EUR" />
  ```
* Использует `useSpring` и `useTransform` из `framer-motion` для плавного интерполирования числового значения с форматированием через `Intl.NumberFormat`.

### 4.2. Тактильные микро-анимации кнопок (`whileTap`, `whileHover`)
* Для всех кнопок действий (`+ Add money`, `⇄ Exchange`, `Details`, `More`):
  ```tsx
  <motion.button
    whileHover={{ scale: 1.04, y: -2 }}
    whileTap={{ scale: 0.94 }}
    transition={{ type: "spring", stiffness: 400, damping: 17 }}
  >
  ```
* Эффект нажатия дает четкую визуальную отдачу (haptic feel).

## ЭТАП 5: Бесшовные переходы (Shared Layout) и праздничные эффекты

### 5.1. Салют конфетти при успехе (`canvas-confetti`)
* При успешном переводе денег или активации промокода запускается кастомный салют в фирменных неоновых цветах Revolut (`#0666EB`, `#984CFF`, `#00D09C`, `#FFFFFF`):
  ```ts
  confetti({
    particleCount: 80,
    spread: 60,
    origin: { y: 0.8 },
    colors: ['#0666EB', '#984CFF', '#00D09C', '#FFFFFF']
  });
  ```

### 5.2. Анимация перетекания индикатора таббара
* В `BottomTabBar.tsx` под активной иконкой располагается плавающий индикатор с `layoutId="activeTabIndicator"`. При переключении вкладок пилюля плавно «перетекает» под новую вкладку с сохранением объема.

## 3. Критерии приемки и проверка производительности (60 FPS)

1. **Производительность**:
   * Все анимации используют только аппаратно-ускоренные свойства GPU (`transform`, `opacity`). Отсутствуют перерасчеты `layout` и `reflow`.
   * Частота кадров строго держится на уровне 60 FPS (120 FPS на экранах ProMotion / 120Hz).
2. **Адаптивность**:
   * Жесты одинаково безупречно работают как на сенсорных экранах смартфонов (touch), так и при управлении мышью на десктопе.
3. **Сохранение финансовой точности**:
   * Анимированный счетчик цифр гарантированно заканчивает прокрутку на точном значении центов/копеек без ошибок округления с плавающей точкой.
